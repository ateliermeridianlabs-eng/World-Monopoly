# World Monopoly

A 2D economy-heavy Monopoly variant played on real world cities.

## Assets

`assets/cities/` holds the city tile art as WebP, one file per city, named with a lowercase ASCII slug (e.g. `new-york.webp`, `washington-dc.webp`).

Currently included: all 8 USA cities (512x512) and all 8 South America cities (about 210x220, original size).
